// PlatformerGen room templates — 10 x 8, rows TOP first.
// Legend: . empty  # solid  = one-way  ^ hazard  H ladder  $ pickup  e enemy  B breakable
//         ? 50% solid   ! 50% hazard   (S/E markers are kept only in the start/end room)
//
// EXIT CONTRACT (the generator trusts this — keep it or levels break):
//   L / R : side column (col 0 / col 9) is open in rows 3..6 (4 rows above the floor row).
//   U     : top row has an opening at cols 4-5.
//   D     : bottom row has an opening at cols 4-5, and cols 4-5 are reachable from L and R.
//   Every path template must be traversable L<->R in BOTH directions with the project's
//   movement profile (defaults: 1-tile body, ~3.2-tile jump). Run the validator after edits.
//   RULE OF THUMB for the default profile: rises <= 2 tiles, pits <= 4, spike runs <= 2.
//   Anything the player should be able to stand on (pickups, exits) must obey the same limits.
//   Never put '?' blocks above a hazard run: they steal the headroom the jump over it needs.
// mirror=1 lets the generator flip the room horizontally (L/R swapped) for variety.

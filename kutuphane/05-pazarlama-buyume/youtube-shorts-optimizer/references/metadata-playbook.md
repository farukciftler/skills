# Metadata Playbook — Titles, Hashtags, Tags, Descriptions

Ground rule: metadata cannot save a weak video, but wrong metadata can sink a good one — by mis-categorizing it and seeding it to the wrong audience, whose swipes then suppress it. Fix metadata to be *accurate and magnetic*, in that order.

## Titles

The title does two jobs on Shorts: (a) it's overlaid in the feed, so it must function as a text hook; (b) Shorts now appear in YouTube search and Google, so it should carry the main keyword. Hook first, keyword as early as naturally possible.

**Hard rules**
- ≤ 60 characters total; assume only ~40 are visible on the mobile overlay — front-load the payload.
- No hashtag stuffing in the title (max 1 if any; hashtags belong in the description).
- Never promise what the video doesn't deliver — swipe-away + satisfaction surveys punish it within the seed test.
- No ALL CAPS walls, no emoji spam (1 emoji max, only if on-brand).
- Sentence case or natural casing; write like a human, not a keyword string.

**Formula bank** (adapt, don't template-fill):
1. Open loop: "I tested X for 30 days and something broke"
2. Bold claim: "This $12 tool replaces your $900 editor"
3. Enemy/contrarian: "Stop doing X. It's killing your Y"
4. Specific number + outcome: "3 settings that doubled my retention"
5. Curiosity gap w/ specificity: "The reason 90% of Shorts die at second 4"
6. POV/situation: "POV: your first day as a sushi apprentice"
7. Status reversal: "Broke at 30, this is what I sold first"
8. Direct question the target can't not answer: "Why is your B-roll so ugly?"
9. Stakes: "If this fails I lose the shop"
10. Search-intent (evergreen/tutorial Shorts): "How to [exact query] in 30 seconds"

For each fix, offer 2–3 variants across different formulas and mark the recommended one with the reason (feed-hook strength vs. search value).

## Hashtags

- **2–5 total**, all niche-specific. Specific beats broad: `#sourdoughstarter` > `#food`.
- Placement: **description**, not title. The first 3 description hashtags render as clickable links above the title — choose those three deliberately.
- **> 15 hashtags anywhere on the video → YouTube ignores every hashtag.** This is a common silent failure; always count when auditing.
- `#Shorts` is unnecessary — format is auto-detected from aspect ratio/length. Not harmful, just wasted slot.
- Delete `#viral`, `#fyp`, `#trending`, `#foryou` on sight: zero categorization value, mis-trains the audience model, looks spammy.

## Tags (the hidden tag box)

What to tell users, because most have this backwards: tags are a **minor** signal. YouTube's own upload page says they play a minimal role. Retention and packaging matter ~100x more. But:

- **Misleading tags actively hurt** — they anchor the video to the wrong context, the wrong audience gets seeded, they swipe, distribution dies. Removing wrong tags is a real fix; adding "better" tags is a marginal one. Say this explicitly when a user asks you to "fix tags" — reset their model of what tags do.
- Sensible use: 5–12 focused tags, 2–3-word phrases, broad → specific (e.g., `cooking` → `weeknight dinners` → `one pan chicken recipe`). Reinforce the title's keywords. Include 1–2 common misspellings of your core term if relevant (their one genuinely documented use).
- Budget: 500 characters total. Never max it — stuffing dilutes the context anchor.

## Descriptions

- First line: restate/extend the hook with the primary keyword — it's indexed and sometimes shown.
- 1–3 short lines is enough for most Shorts; evergreen/tutorial Shorts benefit from 2–3 sentences of genuinely descriptive, keyword-bearing text (they live in search for months).
- Then the 2–5 hashtags.
- A "related video" link and a pinned comment with a question are cheap engagement levers — suggest when relevant.

## Common mistakes table (use in audits)

| Mistake | Why it hurts (mechanism) | Fix |
|---|---|---|
| Title = filename or "day 47 vlog" | No feed hook → seed-test swipes → no fan-out | Rewrite with formula bank |
| `#viral #fyp #shorts #trending` | Mis-categorization + spam look | 2–5 niche hashtags |
| 20+ hashtags | ALL hashtags ignored (>15 rule) | Cut to ≤5 |
| Tags copied from a big unrelated channel | Wrong audience seeded → high swipe rate | Delete; 5–12 accurate tags |
| Clickbait title, unrelated payoff | Mid-video drop + bad satisfaction surveys | Align title to the actual payoff |
| Keyword-stuffed description wall | No ranking benefit, spam signal | 1–3 clean lines + hashtags |
| Metadata in wrong language for the audience | Splits/confuses audience model | Match target market language |
| Optimizing tags while hook is broken | Fixing the 1% lever, ignoring the 90% lever | Redirect effort to hook/retention |

## Worked example

**Before**
- Title: `my morning routine video #shorts #viral #fyp #motivation #routine #morning`
- Tags: `mrbeast, minecraft, funny, viral video, shorts`
- Description: *(empty)*

**After**
- Title: `5AM routine of a Michelin line cook` *(open loop + specificity + search keyword)*
- Description: `What 5AM looks like before a Michelin service — full station prep in 40 seconds.` + `#michelin #linecook #kitchenlife`
- Tags: `morning routine, chef morning routine, michelin kitchen, line cook day, restaurant prep`
- Rationale to show the user: the old tags anchored the video to gaming/entertainment audiences who swipe cooking content instantly; the fixed set anchors it to food/career-curiosity audiences, and the title now works as the hook the first frame needs.

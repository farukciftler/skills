# On-Page Metadata & OpenGraph Reference

## Standard Meta Tags Template
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  
  <!-- Primary Title & Meta Description -->
  <title>Descriptive Target Page Title | Brand Name</title>
  <meta name="description" content="Clear, engaging description between 120-155 characters that summarizes the page content." />
  <link rel="canonical" href="https://example.com/target-page" />

  <!-- Open Graph / Social Media Preview -->
  <meta property="og:title" content="Descriptive Target Page Title | Brand Name" />
  <meta property="og:description" content="Engaging preview description for social shares." />
  <meta property="og:type" content="website" />
  <meta property="og:url" content="https://example.com/target-page" />
  <meta property="og:image" content="https://example.com/assets/og-image-1200x630.png" />
  <meta property="og:image:width" content="1200" />
  <meta property="og:image:height" content="630" />
  <meta property="og:site_name" content="Brand Name" />

  <!-- Twitter / X Cards -->
  <meta name="twitter:card" content="summary_large_image" />
  <meta name="twitter:title" content="Descriptive Target Page Title | Brand Name" />
  <meta name="twitter:description" content="Engaging preview text." />
  <meta name="twitter:image" content="https://example.com/assets/og-image-1200x630.png" />
</head>
```

## E-E-A-T Content Guidelines (Experience, Expertise, Authoritativeness, Trustworthiness)
1. **Author Verification**: Display clear author credentials, bios, and links to author entity pages.
2. **Freshness & Timelines**: Include visible `datePublished` and `dateModified` timestamps.
3. **Citation & Sources**: Link out to authoritative primary sources and industry studies.
4. **Unique Perspective**: Provide original insights, empirical data, or hands-on expertise rather than generic AI summaries.
